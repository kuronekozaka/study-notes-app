Study Notes

Study Notesは、タブレットで授業ノートを手書きするための個人用Androidアプリです。オープンソースの手書きノートアプリLinwood Butterflyをもとにしています。

主な機能

  • ペン、蛍光ペン、消しゴム、投げ縄による手書き
  • 固定サイズのページを縦に並べたノートと、PDFへの書き込み
  • 2つのノートを並べる分割表示
  • 端末のノートを、フォルダ構造のまま利用者自身のGoogleドライブへコピーする同期（変更したファイルだけを送信）

Googleドライブとの連携

同期では、このアプリが作成したファイルだけを扱う権限（drive.file）を使います。利用者がドライブに保存している他のファイルは読みません。詳しくはプライバシーポリシーをご覧ください。

Study Notes is a personal Android app for handwritten class notes, based on Linwood Butterfly. It can copy notes to the user's own Google Drive using only the drive.file scope.
