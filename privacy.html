プライバシーポリシー

Study Notes ／ 最終更新日: 2026年11月12日

1. 扱うデータ

ノートは端末のアプリ専用フォルダに保存します。利用者がGoogleドライブ同期を有効にした場合だけ、そのノートを利用者自身のGoogleドライブの「Study Notes」フォルダへアップロードします。

2. Googleユーザーデータの利用

このアプリが求める権限は https://www.googleapis.com/auth/drive.file（このアプリが作成したファイルだけを参照・作成・更新・削除する権限）だけです。利用者が別に作ったドライブ上のファイルは読みません。アカウントのメールアドレスは、接続中のアカウントを画面に表示するためだけに端末内で使います。

Googleから受け取った情報の利用と他のアプリへの移転は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

3. 第三者への提供

開発者のサーバーはありません。ノートやGoogleユーザーデータを開発者や第三者へ送信・販売・共有しません。広告や分析ツールも使いません。

4. 削除

アプリの「接続を解除」でドライブへのアクセスを取り消せます。Googleアカウントの「サードパーティのアプリとサービス」からも取り消せます。ドライブ上のファイルは利用者が自由に削除できます。

5. 問い合わせ

Googleの同意画面に表示されるサポートメールアドレスへご連絡ください。

Summary (English)

Study Notes stores notes on the device. Only when the user enables Google Drive sync, notes are uploaded to the user's own Drive using the drive.file scope, which limits access to files created by this app. No data is sent to the developer or any third party, and no ads or analytics are used. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
